# 月度宏观数据页面设计

**日期：** 2026-08-14  
**状态：** 用户已确认  
**范围：** 在现有中国宏观脉搏网页中重构月度数据板块，保留已完成的国内周报板块。

## 1. 目标

构建一个研究型月度宏观数据页面，让读者先识别各类数据的最新版本和更新时间，再按八个固定章节查看核心数字、2019 年以来的趋势图和详细解读。

页面必须回答四个问题：

1. 每组数据目前更新到哪个统计期；
2. 官方何时发布该版本；
3. 本站何时完成核对和更新；
4. 下一期数据预计何时发布。

页面只展示已经核对的官方数据。尚未发布的数据不得使用预测值、市场一致预期或插值替代。

## 2. 已确认的产品选择

- 采用“总览 + 八个固定研究章节”的 B 方案。
- 主图历史区间统一为 2019 年至今。
- 顶部同时显示最新数据期、官方发布日期和本站更新时间。
- 尚未发布的新一期只显示预计发布日期，不提前填数。
- 月度页面与周报页面通过现有顶部视图按钮切换，互不覆盖。
- 延续华泰宏观蓝色和红色视觉体系，不复制华泰固收页面配色。

## 3. 数据来源与更新方式

采用“官方静态快照”方案。开发或更新时，由编码代理核对官方发布，写入审阅过的本地静态数据；客户浏览器不抓取、解析或请求外部数据。

四类权威来源为：

- 国家统计局：PMI、CPI、核心 CPI、PPI、社会消费品零售总额、固定资产投资、工业增加值；
- 中国人民银行：新增人民币贷款、社会融资规模增量和存量、M1、M2；
- 财政部：一般公共预算、政府性基金预算及相关分项；
- 海关总署：进出口金额、同比增速、贸易差额及结构分项。

每一条进入产品的数据都必须保存官方来源链接、统计期、发布日期、单位、口径和审核状态。不同口径的数据不得拼接为一条连续趋势线。

## 4. 页面结构

### 4.1 月度页标题区

标题显示“月度宏观数据”，并显示本站最近一次完成审核更新的时间。标题区用一句简短概览概括当期增长、价格、信用、财政和外需的主要边际变化。

### 4.2 顶部版本矩阵

版本矩阵包含八张状态卡，每张卡固定显示：

- 数据名称；
- 最新数据期；
- 官方发布日期；
- 本站更新时间；
- 下一次预计发布日期；
- 数据状态；
- 官方来源入口。

状态仅使用三种：

- `最新版`：本站数据与已核对的官方最新版一致；
- `即将发布`：下一期尚未发布，页面继续展示当前最新版；
- `待同步`：官方已经发布新版本，但本站尚未完成审核。

状态由静态数据明确记录，不依赖客户端实时抓取结果。预计发布日期必须来自官方发布日历或稳定的官方发布安排，并明确标为“预计”。

### 4.3 八个固定章节

#### 01 PMI

默认展示制造业 PMI、非制造业商务活动指数和综合 PMI 产出指数。主要图表包括三项总指数趋势，以及生产、新订单等关键分项。50 为显著参考线。

#### 02 通胀

默认展示 CPI、核心 CPI 和 PPI。同比和环比必须分图或清楚区分，不能在读者难以辨认的情况下共用一个坐标。详细区可显示食品、非食品及主要工业行业价格贡献。

#### 03 社会消费品零售

默认展示社零总额同比、商品零售和餐饮收入。详细区可展示实物商品网上零售、汽车以外消费及主要限额以上商品分项。总额、同比和累计同比必须分别标明口径。

#### 04 固定资产投资

默认展示整体固定资产投资、制造业投资、基础设施投资和房地产开发投资。累计同比是主要官方口径；若使用单月估算，必须明确标注其计算方式，不与官方累计同比混画。

#### 05 工业增加值

默认展示规模以上工业增加值同比，以及采矿业、制造业、电力热力燃气及水生产供应业。详细区可展示高技术制造业和装备制造业。

#### 06 信贷与社会融资

默认展示新增人民币贷款、社会融资规模增量、社融存量同比、M1 和 M2。流量指标与存量增速分图；新增贷款和社融增量可提供历年同月比较，避免只比较相邻月份。

#### 07 财政数据

默认展示一般公共预算收入、一般公共预算支出、税收收入、政府性基金预算收入和国有土地使用权出让收入。主要使用累计同比，同时显示累计金额；财政收入和支出不使用同一含义的颜色暗示。

#### 08 进出口数据

默认展示美元口径出口同比、进口同比和贸易差额。详细区可展示主要贸易伙伴和主要商品结构。人民币与美元口径不得混接；页面应明确当前图表所用币种。

### 4.4 默认展示与展开解读

每个章节默认展示核心数字和一至三张主要图。点击“展开完整解读”后显示：

- 更多分项图；
- 当期边际变化解读；
- 指标口径与单位；
- 官方来源链接；
- 版本和修订说明。

## 5. 图表规则

- 主图覆盖 2019 年至最新官方统计期；当前年度尚未发生的月份保留为空白，不补零、不外推。
- 最新值直接标在图中，不另加“最新值说明”类内部备注。
- 图例必须包含指标名称和单位；同比、环比、累计同比必须清楚区分。
- 参考线只用于具有明确经济含义的水平，例如 PMI 的 50 或同比的 0。
- 单位不兼容的指标不得共用坐标；确需比较时使用定基指数，并在标题下明确基期。
- 图表必须由归一化静态数据生成，不使用截图代替可读数据图。
- 所有图表提供可访问名称；颜色不是唯一的信息编码方式。

## 6. 数据模型边界

月度数据使用独立的页面读模型，至少包含：

- 页面级 `siteUpdatedAt` 和概览；
- 八个章节的稳定 ID 和标题；
- 每章的 `latestPeriod`、`officialPublishedAt`、`nextExpectedRelease`、`status` 和 `source`；
- 图表标题、单位、口径、横轴、数列及可选参考线；
- 2019 年以来的日期和值；
- 默认解读和展开解读。

报告事实、数值和日期全部位于数据文件，不硬编码在 React 组件中。现有通用数据域可以保留，但不得用一个报告日期代表八种发布节奏不同的数据。

## 7. 缺失、修订与错误处理

- 官方尚未发布：继续展示上一版，并标记 `即将发布`；
- 官方已发布但尚未核对：保留上一版，并标记 `待同步`；
- 历史序列缺值：图表断线并保留空白，不进行插值；
- 官方修订历史值：替换为最新官方版本，并在章节中记录修订说明；
- 来源页面不可访问或口径不清：该数据不得标记为已验证，也不得进入默认图表；
- 组件数据异常：由章节级错误边界隔离，不能导致周报或其他月度章节不可用。

## 8. 验证与完成标准

自动化测试至少覆盖：

1. 八个章节存在且顺序固定；
2. 每章都有最新数据期、官方发布日期、本站更新时间和来源；
3. 所有默认图表历史起点不晚于 2019 年；
4. 未发布月份为缺失值，不能显示为零或预测；
5. 不兼容单位和比较口径不能进入同一数列；
6. 顶部版本矩阵正确展示三种状态；
7. 周报页面和月报切换继续可用；
8. 桌面和移动端图表可读，横向表格可通过键盘访问；
9. 无自动检测到的严重无障碍问题；
10. `npm run verify` 全部通过。

## 9. 非目标

- 不建立运行时抓取、爬虫或外部 API 调用；
- 不自动发布未经人工核对的数据；
- 不加入预测值、市场一致预期或情景预测；
- 本阶段不改动周报数据口径和周报四个固定章节；
- 不把八类数据压缩成只有数字、没有趋势图的卡片页。
