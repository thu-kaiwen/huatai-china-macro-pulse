# 周报 A 版页面重构设计

## 目标与范围

将现有单页静态宏观研究页面的“周度”部分重构为华泰证券宏观团队的周报阅读页。首期样本使用 `国内周报0731.docx`（2022-07-31），其图表底稿来自工作区 `data-excel`。本次不改造月报；月度页面后续仅依据国家统计局最新发布数据单独调整。不保留行业景气度板块，也不在浏览器运行时读取 Word 或 Excel。

## 版式与品牌

采用已确认的 A 版：研究摘要优先。页面以“华泰证券宏观团队”为标题，使用深海军蓝作为主色、青绿色作为信息强调色；红色只用于变化方向或风险提示，避免复用固收团队的视觉系统。

从上到下的内容顺序为：

1. 报告日期、标题与“本周宏观观点”；
2. 直接展示报告《一周概览》的审核后摘要；
3. 根据首页概览选出的“核心变化”原始图表；不为填充首屏而展示与概览无关的图；
4. 四个固定主题框架，仅显示标题、短结论和“展开完整解读”入口，不在折叠状态展示图表；
5. 用户点击“展开完整解读”后，在本页展开完整文字分析和该主题全部图表；再次点击可以收起。

“核心变化”图是首屏唯一显示的图表区域：从报告《一周概览》中提及的变化中选择，并按概览文字顺序组织；四个固定主题框架在默认折叠状态不展示任何图表。月度数据与月度页面不属于本轮范围，后续只在取得国家统计局最新发布数据并完成独立审核后更新。

## 首期四个板块

### 1. 高频经济活动跟踪

在核心变化区可选择与首页概览直接对应的上游、中游、下游代表性图；展开后依次展示消费、投资/库存/地产的相关全部图表。首屏结论来自报告：上游重工业生产减速，汽车生产销售保持较快增长，地产和土地成交回升。

### 2. 价格指标及通胀变化

核心变化区可选择原油/大宗商品、运价、农产品或猪肉中与概览最直接对应的图；展开后展示煤炭、水泥、化工品、粮食与农产品图表。首屏结论来自报告：原材料价格有所回升，煤价持续下行，运价和部分农产品价格走弱。

### 3. 利率、汇率及金融市场环境

核心变化区可选择资金利率、国债收益率或信用利差、人民币汇率中与概览最直接对应的图；展开后展示同业存单、债券发行、地产债、股票融资和权益市场图表。首屏结论来自报告：短期流动性平稳，融资环境偏弱，人民币兑美元小幅上行。

### 4. 宏观政策跟踪

核心变化区可在报告概览直接提及政策工具时展示公开市场操作/利率债发行等政策底稿图；展开后提供本周重要宏观数据和事件、报告的观察点与风险提示。

## 数据与图表交付

每周更新在开发会话内完成：读取用户提供的 Word/PDF 报告与 `data-excel` 底稿，审核标题、报告期、图名、来源和引用口径后，将精选图及展开图导出为项目静态图片，并写入报告特定的静态清单。浏览器仅渲染已导出的静态图片和审核后文本，绝不解析原始报告或 Excel。

图表清单的每一项至少包含：唯一标识、板块、图标题、底稿相对路径、工作表或图表定位、报告期、来源说明、首屏/展开位置、替代文本。底稿找不到、图表无法导出、报告图名与底稿不一致时，不显示该图并在开发阶段报出问题；不得以推测数值或占位数据替代。

## 关键数据卡

首期可从报告直接给出的核心变化中选择四项数据卡，例如：乘用车零售同比 +24.7%、30 城商品房成交面积同比 -14.1%、布伦特原油 114 美元/桶、DR007 上行 15bp。最终上线前必须逐项和相应 Excel/报告来源核对数值、统计期和单位；任何未核验项不会显示。数据卡与核心图共同由首页概览驱动。

## 组件边界

- `WeeklyReportHero`：标题、报告期、观点与关键数据卡；
- `WeeklySection`：一个主题的精选图、摘要和展开状态；
- `WeeklyChartFigure`：静态图、标题、来源、报告期、替代文本；
- `WeeklyReportData`：报告元数据、审核后摘要、指标卡、章节文字和图表清单。

现有周度数据和旧的行业矩阵将从周报阅读路径中移除，但不对月报路径作无关改造。组件不得硬编码某期报告数值或文件名。

## 错误处理与验证

如果某张静态图缺失，页面显示该图不可用的明确提示，仍渲染其余内容。展开/收起必须可使用键盘操作，并正确更新可访问性属性。新增数据和图表清单须有单元测试，覆盖四个板块顺序、报告文字与图表归属、缺图提示、展开交互和行业板块不再出现在周报路径中。

实现后运行相关单元测试、生产构建、浏览器渲染检查和 `npm run verify`。由于报告是 2022 年历史样本，页面需清晰显示其报告日期，且不得与现有 2026 年数据混合生成趋势或“最新”结论。
