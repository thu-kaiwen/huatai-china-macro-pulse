# 中国宏观脉搏

华泰证券研究所的静态宏观研究终端。页面把获批月报与周报整理为可切换、可追溯的宏观指标、政策事件、行业观察和风险提示；不在浏览器中抓取、解析或推断外部数据。

## 本地运行

```bash
npm install
npm run dev
```

提交前运行完整验证：

```bash
npm run verify
```

生成静态产物：

```bash
npm run build
```

`npm run verify` 依次执行 ESLint、TypeScript、Vitest、生产构建和 Playwright。Playwright 覆盖 1440×1000 桌面视口与 390×844 移动视口，并对浅色、深色主题运行 axe 自动无障碍检查。

当前数据仅来自以上获批文章。页面内每项报告、观测、叙事、事件与风险都应能回溯到对应原文；不要添加未经批准的网页或在线接口。

## 数据更新流程

新报告必须先在网站之外完成读取、解析、口径核验与人工复核。网站没有在线抓取器或解析器，也不应把解析逻辑加入 React 组件。复核完成后，再按规范化数据模型更新：

1. 在 `src/data/reports.ts` 登记报告元数据、作者、统计期、发布日期和获批原文 URL。
2. 在 `src/data/metricDefinitions.ts` 新增或复用指标定义，明确单位、原生频率和方法口径。
3. 在 `src/data/observations.ts` 录入观测值、比较类型、报告 ID、来源摘录和统计期。只有经原文逐项复核的观测才能设置 `confidence: "verified"`；未核验值不得进入图表、ticker 或卡片。
4. 按报告内容更新 `src/data/narratives.ts`、`src/data/policyEvents.ts` 和 `src/data/risks.ts`，保持每条记录的报告关联与来源语义。
5. 运行 `npm run verify`，确认数据校验、筛选行为、静态构建、双视口 E2E 与 axe 检查全部通过。

不要直接编辑组件来“写死”新报告展示。组件只消费规范化 schema；数据差异应留在 `src/data/` 中。

### 日期审计待办

周报正文中有 20 条市场观测只写“上周”，当前统一以 `2026-08-02` 保存为“报告周截至”锚点。该日期不代表每个市场的最后交易日已经逐项核验；发布前仍须回看原图横轴或注脚，确认实际数据截止日后再统一修订。对应 `sourceText` 与指标 `methodology` 均保留了这项限定，页面不得把它改写为已验证交易日。

二手房成交面积的 4 条观测暂按相邻高频地产窗口 `2026-07-26` 锚定，具体观测周同样待原图日期标题确认。

## 趋势可见性规则

- 原生周频或月频趋势：同一指标、同一频率、同一比较口径至少有 2 个不同 `periodEnd` 的 `verified` 观测才显示；同日重复记录不计作两期。
- 跨频趋势：同一指标至少有 2 个不同 `periodEnd` 的已核验周频观测和 1 个已核验月频观测，且所有观测的比较口径一致；指标定义还必须声明 `nativeFrequency: "mixed"` 并具备完整单位与方法说明。
- 单点、未核验值、单位或方法不完整、频率声明不兼容的数据不会绘制趋势。

因此初始数据集不会显示趋势浏览器；这是对样本不足的主动保护，不是加载错误。

## 内容边界

本项目用于展示华泰证券研究所获批研究资料，不构成投资建议。发布前仍需由内容负责人确认版权、免责声明、作者信息、引用精度和原文链接均符合内部要求。
